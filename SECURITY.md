# Security

Please report vulnerabilities privately through GitHub's "Report a vulnerability" button (Security tab), not in a public issue. Include steps to reproduce and the version (`riskaware version`).

Scope that matters most: anything that could place an order the user did not intend (bypassing the paper/live switches, the guards or the kill switch), leak API keys, or let third-party text (news, filings, LLM output) change orders beyond the documented bounds.

请通过 GitHub 的 "Report a vulnerability"（Security 标签页）私下报告安全问题，不要发公开 issue。最重要的问题包括：可能让用户没打算下的单被发出（绕过模拟/实盘开关、安全开关或一键停止）、泄露 API key，或者让第三方文本（新闻、公告、LLM 输出）超出文档规定的范围影响订单。
