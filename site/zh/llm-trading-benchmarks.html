LLM 交易智能体基准对比

已经有不少基准在问 LLM 智能体会不会交易。它们的区别在于：智能体做决定时能知道什么，结果能不能重跑，模型会不会只是记得测试的那段行情。这一页把我们的 LLM 交易智能体榜单所用的基准 rta-bench-1 和另外八个放在一起，就这几点逐项对比。

除我们自己这一行，每一行都摘自论文的 arXiv 摘要页，读取于 2026 年 11 月 13 日。「未说明」指摘要页没有写，论文正文可能有。发现写错的地方，欢迎开 issue 或 PR 指正。

rta-bench-1 不一样的地方

  • 按分钟回放新闻。实时基准靠交易当下来避免偷看未来，但明年发布的模型再去交易这些日子时，已经读过关于它们的报道。rta-bench-1 回放历史：每条新闻在发布的那一分钟送到，每次运行都要通过对模型所见内容的防偷看检查。很多新闻回测按日历日期把新闻和价格对齐；在我们的例子里，这会把一个每笔亏 6.7 bp 的信号变成每笔赚 32 bp。
  • 三种不同的市场。上涨的 2026 年、2022 年加息熊市和 2020 年暴跌，只在普涨时表现好的模型会被看出来。
  • 记忆是量出来的，不是假设没有。同一个模型在每个时段盲测和实名各交易一次。训练截止日之后的成绩参与排名，之前的单独列出，旁边是记忆探针的结果。只遮住名字，能看出模型不靠名字时怎么做；两种都跑，才看得出名字对它值多少。
  • 一条成绩就是一个文件。条目里存着模型的每一条回复，持续集成把它们放进回测重放，数字必须一致。提交一个模型，就是开一个 PR、加一个 JSON 文件。
  • 免费。pip install risk-aware-trading-agents 就带上三个时段的价格和回测器，价格也在 Hugging Face 上。结论基于按发布时间回放的新闻；标题数据有许可限制、不随包分发。

实时竞技场能回答冻结时段回答不了的问题：模型今天面对没人见过的新闻时怎么交易。冻结时段回答另外几个：结果能不能重复、能不能比较、能不能核对。两类基准互为补充。
