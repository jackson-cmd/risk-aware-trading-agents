LLM trading agent benchmarks compared

Several benchmarks now ask whether LLM agents can trade. They differ in what the agent may know when it decides, whether a result can be run again, and whether the model could simply remember the test period. This page sets rta-bench-1, the benchmark behind our LLM trading leaderboard, next to eight others on those points.

Every row except ours is taken from the paper's arXiv abstract page, read on 13 November 2026. "Not described" means the abstract page does not say; the full paper may. Corrections are welcome as an issue or a pull request.

Where rta-bench-1 differs

  • News by the minute, in a replay. Live benchmarks avoid look-ahead by trading the present, but a model released next year cannot trade those days without having read about them. rta-bench-1 replays history instead: each headline arrives at the minute it was published, and every run passes a look-ahead check of what the model was shown. Many news backtests join headlines to prices by calendar date; in our example that turns a signal that loses 6.7 bp a trade into one that makes 32 bp.
  • Three different markets. A rising 2026, the 2022 rate-hike bear market and the 2020 crash, so a model that only does well when everything rises shows as such.
  • Memory is measured, not assumed away. The same model trades each period blind and with names. Scores after its training cutoff are ranked, and earlier ones are listed apart, next to a memory probe. Hiding the names shows what a model does without them; running it both ways shows how much the names were worth.
  • A result is a file. An entry holds every reply of the model, so continuous integration replays it through the backtest and the numbers must match. Submitting a model is a pull request that adds one JSON file.
  • Free to run. pip install risk-aware-trading-agents brings the prices of the three periods and the backtester, and the prices are also on Hugging Face. The results are based on news replayed by publication time; the headline data has license restrictions and is not distributed with the package.

Live arenas answer a question frozen periods cannot: how a model trades today, on news nobody has seen. Frozen periods answer the others: whether a result can be repeated, compared and checked. The two kinds of benchmark complement each other.
